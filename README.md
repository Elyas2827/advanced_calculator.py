# 🧮 Advanced Python Calculator

A professional console-based Advanced Calculator built using Python.  
This project demonstrates structured programming, functions, loops, error handling, and history tracking.

---

## 🚀 Features

✔ Addition (+)  
✔ Subtraction (-)  
✔ Multiplication (*)  
✔ Division (/)  
✔ Power (x^y)  
✔ Modulus (%)  
✔ Floor Division (//)  
✔ Square Root  
✔ Calculation History  
✔ Clear History Option  
✔ Input Validation  
✔ Error Handling (Division by zero, invalid input)
